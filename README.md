## Featured projects

- **[terraform-aws-vpc-eks](https://github.com/bathyz/terraform-aws-vpc-eks)** — Terraform IaC for a multi-AZ AWS VPC (public/private subnets, NAT gateway) and an EKS cluster with a managed node group.
- **[cicd-flask-k8s](https://github.com/bathyz/cicd-flask-k8s)** — Flask microservice with a full CI/CD pipeline: GitHub Actions runs tests, builds a Docker image, pushes to GHCR, and prepares a rolling Kubernetes deployment.
- **[prometheus-grafana-monitoring-stack](https://github.com/bathyz/prometheus-grafana-monitoring-stack)** — Self-contained observability stack: Prometheus, node-exporter, Alertmanager, and Grafana wired together with docker-compose, with dashboards and alert rules provisioned automatically.
- **[ansible-server-hardening](https://github.com/bathyz/ansible-server-hardening)** — Ansible playbook that provisions a hardened Ubuntu Nginx web server: ufw firewall, fail2ban, unattended security upgrades, and a security-headers Nginx config.
